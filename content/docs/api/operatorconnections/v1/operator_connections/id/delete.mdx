---
title: Delete an operator connection
description: |
  Removes a connection you created with your own credentials. An API
  key belongs to one project while a connection belongs to the whole
  business, so a deletion that would affect more than the key's own
  project is refused.

  **Errors:** `409 operator_connection_in_use` — the connection has
  received payments; switch it off in the dashboard instead,
  `409 operator_connection_managed` — the connection was provisioned by
  Wire and is managed in the dashboard,
  `409 operator_connection_shared` — another project of the business
  has this operator switched on.
