title: Update a webhook endpoint
description: |
  Changes the URL, the subscribed events, or pauses/resumes delivery.
  Only the fields you send change.

  - `url` — on an endpoint that was never verified the URL is replaced
    at once. On a verified endpoint the new URL is **staged**: events
    keep going to the old URL until the new one passes verification
    from the dashboard.
  - `enabled_events` — replaces the whole list.
  - `status` — `disabled` pauses delivery, `enabled` resumes it. Setting
    `enabled` does not skip verification: an unverified endpoint still
    receives nothing.

  **Errors:** `400 webhook_url_invalid`, `400 enabled_events_invalid`,
  `400 parameter_invalid` (`status` not `enabled`/`disabled`),
  `404 resource_missing`.
