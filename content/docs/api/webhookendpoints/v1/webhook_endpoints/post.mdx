title: Create a webhook endpoint
description: |
  Registers the project's webhook endpoint. The response contains the
  signing `secret` (`whsec_…`) — **shown only once**; store it.

  The endpoint starts in status `pending` and receives nothing until it
  is verified from the dashboard: Wire sends a signed
  `endpoint.verification` ping and your URL must answer `2xx`.

  **Errors** (besides the common ones):
  - `409 webhook_endpoint_exists` — the project already has its one
    endpoint; update it instead.
  - `400 webhook_url_invalid` (`url`) — not an absolute `http(s)` URL,
    or it points at `localhost` / a private, loopback or link-local IP.
  - `400 enabled_events_invalid` (`enabled_events`) — an unknown event
    name, or more than 20 entries.
