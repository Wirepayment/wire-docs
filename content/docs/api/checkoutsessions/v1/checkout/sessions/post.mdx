title: Create a checkout session (hosted payment page)
description: |
  Opens a Wire-hosted payment page for a PaymentIntent and returns its
  `url`. Redirect the buyer there. The page lists the operators the
  buyer can pay with, confirms the intent, shows the QR code / bank-app
  links, and redirects to `success_url` / `cancel_url` when done.

  Create the session right after creating the intent: the intent must
  still be in `requires_payment_method` (not confirmed, not canceled,
  not expired). Do not call `/confirm` yourself for this intent.

  **Errors** (besides the common ones):
  - `400 invalid_request_error` (`payment_intent`) — `payment_intent`
    omitted.
  - `404 resource_missing` — no such PaymentIntent in this project.
  - `400 payment_intent_unexpected_state` (`payment_intent`) — the
    intent is not awaiting payment.
  - `400 checkout_url_invalid` (`success_url`) — `success_url` or
    `cancel_url` is not an absolute `http(s)` URL.
  - `403 connector_required` / `403 settlement_account_required`.
