---
title: Cancel a PaymentIntent
description: |
  Cancels an intent that has not been paid. Allowed from
  `requires_payment_method`, `requires_action`, `requires_capture` and
  `processing`. If an operator invoice was already created, Wire voids
  it where the operator supports that. Sends a
  `payment_intent.canceled` event.

  Idempotent: canceling an intent that is already `canceled` returns
  it unchanged and sends no second event.

  **Errors:** `400 payment_intent_unexpected_state` — the intent already
  `succeeded`, or its status changed while canceling (re-read it);
  `404 resource_missing`. Because this is a `POST` under
  `/v1/payment_intents`, it can also return `403 connector_required` /
  `403 settlement_account_required`.
