---
title: Олон данс
description: Бизнес олон данстай бол төлбөр бүрт аль данс руу орохыг сонгоно.
---

Бизнес тань хэд хэдэн банкны данстай бол төлбөр **бүрт** аль данс руу орохыг
сонгож болно. Сонгоогүй төлбөр таны **үндсэн** (оператор бүрт тохируулсан) данс
руу орно.

<Callout type="warn">
  Бүх данс **бизнесийн эзний нэр дээр** байна. Бусдын нэр дээрх данс
  зөвшөөрөгдөхгүй: [Хэний нэр дээр бүртгэх](/docs/guides/business-ownership).
</Callout>

## Дансаа олох

Дансууд дашбоардын **Данс** хэсэгт нэмэгдэнэ. API-аар жагсаалтыг авна:

```bash
curl https://api.wire.mn/v1/bank_accounts \
  -H "Authorization: Bearer $WIRE_SECRET_KEY"
```

Хариунд данс бүрийн `id` (`ba_…`), банк, дансны дугаарын **сүүлийн 4 орон**,
эзэмшигчийн нэр ирнэ. `settlement_selectable: true` данс л төлбөрт сонгогдоно.

<Callout type="info">
  API түлхүүр **зөвхөн өөрийн бизнесийн** дансыг харна. Нэг эзэмшигч хэд хэдэн
  бизнестэй байсан ч нэг бизнесийн түлхүүр нөгөө бизнесийн дансыг харахгүй,
  сонгож ч чадахгүй. Нэг бизнесийн бүх project ижил дансуудыг хуваалцана.
</Callout>

## Төлбөр бүрт данс сонгох

PaymentIntent үүсгэхдээ `settlement_account` өг:

```bash
curl https://api.wire.mn/v1/payment_intents \
  -H "Authorization: Bearer $WIRE_SECRET_KEY" \
  -H "Idempotency-Key: order-1024" \
  -H "Content-Type: application/json" \
  -d '{"amount": 15000, "settlement_account": "ba_m2qk7t4xw5nbv3rj6yhc2dpa4e"}'
```

- Төлбөр **зөвхөн тэр данс** руу орно. Данс салгагдсан бол төлбөр татгалзагдана —
  өөр данс руу хэзээ ч шилжихгүй.
- Intent нь нэхэмжлэх бүрт данс зааж чаддаг оператороор хязгаарлагдана
  (`allowed_operators` хариунд харагдана).
- Алдаа: `400 settlement_account_invalid` (таны данс биш эсвэл холбогдоогүй),
  `400 settlement_account_unsupported` (`allowed_operators`-д тийм оператор алга).

## Кодгүйгээр — төлбөрийн линк

[Төлбөрийн линк](/docs/guides/payment-links) үүсгэхдээ **Орлого орох данс**-аа
сонговол тэр линкээр орсон бүх төлбөр сонгосон данс руу орно.
