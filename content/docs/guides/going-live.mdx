Төлбөр хүлээн авахын тулд **таны акаунтад идэвхжсэн операторуудаас** сонгож
идэвхжүүлнэ. Урсгал нь дөрвөн алхамтай:

<Callout type="info">
  Идэвхжүүлэлт бүхэлдээ дашбоард дээр явагдана — код бичих шаардлагагүй.
  Оператор идэвхжиж, project дээрээ асаагдсаны дараа API талд өөрчлөлт
  хэрэггүй: `allowed_operators`-гүй үүсгэсэн PaymentIntent түүнийг автоматаар
  ашиглана.
</Callout>

## 1. Хүсэлт илгээх

Дашбоардын **Холболтууд** хэсгээс оператороо сонгож, алхам алхмаар мэдээллээ
бөглөнө:

- **Бүртгэлийн төрөл** — хувь хүн эсвэл байгууллага.
- **Үндсэн мэдээлэл** — нэр, регистр, үйл ажиллагааны чиглэл. Хувь хүн бол
  **ДАН баталгаажуулалтын мэдээллээрээ** нэг товшилтоор бөглөж болно.
- **Хаяг, холбоо барих** — байршил, утас, имэйл. Бүртгэлийн имэйл,
  баталгаажсан утсаа мөн нэг товшилтоор ашиглана.
- **Орлого хүлээн авах данс** — холбогдсон данснуудаасаа сонгоно; данс
  холбоогүй бол яг энэ алхам дээрээ шинээр холбоно.

Илгээхийн өмнө **Хянах** алхам дээр бүх мэдээллээ нягтална.

## 2. Хяналт

Хүсэлтийг Wire-ийн баг ажлын цагаар хянана. Шийдвэрийг **имэйлээр** мэдэгдэх
бөгөөд дашбоардын холболтын хуудсанд явц нь шат дараалсан төлөвөөр харагдана
(Мэдээлэл → Хяналт → Идэвхжинэ). Татгалзсан тохиолдолд шалтгаан нь
харагдаж, маягт өмнөх мэдээллээрээ бөглөгдсөн байх тул зөвхөн засах
хэсгээ өөрчилж дахин илгээнэ.

## 3. Цахим гэрээ байгуулах

Хүсэлт баталгаажсаны дараа тухайн операторын **үйлчилгээний гэрээг цахимаар**
байгуулна:

1. Гэрээний бүрэн эхийг **PDF-ээр нээж уншина** (уншсаны дараа л
   баталгаажуулах хэсэг идэвхжинэ).
2. Шимтгэлийн нөхцөл, хориглосон үйлчилгээний жагсаалттай танилцсанаа
   баталгаажуулна.
3. **ДАН баталгаажсан иргэний мэдээллээрээ** гэрээг байгуулна — энэ нь гарын
   үсэг зурсантай адил хүчинтэй.

Гэрээний мэдээллийн хэсэгт таны хүсэлтээр илгээсэн мэдээлэл (нэр, регистр,
хаяг), гарын үсгийн хэсэгт ДАН баталгаажсан нэр, регистр орно. Байгуулсан
гэрээгээ холболтын хуудаснаас хэзээ ч **PDF-ээр харах, татах** боломжтой.

## 4. Төлбөр идэвхжинэ

Гэрээ байгуулагдмагц холболт автоматаар идэвхжиж, тухайн оператор:

- [Hosted checkout](/docs/guides/hosted-checkout)-ийн төлбөрийн сонголтод,
- [Төлбөрийн линк](/docs/guides/payment-links)-ийн төлбөрийн хуудсанд,
- API-д — автомат чиглүүлэлт, мөн `allowed_operators`-оор хумьсан бол түүнд

ашиглагдах боломжтой болно.

Мөн **project** бүр тухайн операторыг асаах ёстой (project → Холболтууд).
Асаагаагүй бол тэр project-ийн API key-ээр үүсгэсэн төлбөр уг операторыг
ашиглаж чадахгүй бөгөөд API `connector_required` гэж хариулна.

## Түр унтраах / асаах

Идэвхтэй оператор бүрийг **Холболтууд** хуудасны унтраалгаар түр
зогсоож болно. Унтраасан үед тухайн оператороор шинэ төлбөр үүсэхгүй
(автомат чиглүүлэлт болон төлбөрийн хуудаснаас хасагдана); холболт,
тохиргоо хэвээр үлдэж, дахин асаахад шууд үргэлжилнэ.

<Callout type="warn">
  Оператор идэвхжүүлэхийн өмнө [эзэмшигчийн баталгаажуулалт](/docs/quickstart)
  (утас + ДАН) дууссан байх шаардлагатай.
</Callout>
