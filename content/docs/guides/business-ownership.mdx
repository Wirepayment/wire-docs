---
title: Хэний нэр дээр бүртгэх
description: Бизнес, project, орлого хүлээн авах дансыг зөв эзний нэр дээр бүртгэх заавар.
---

Wire дээр бизнесийг түүний **жинхэнэ эзэн** бүртгүүлж, орлого зөвхөн **эзний өөрийн
нэр дээрх** дансанд орно. Wire платформын AML агент бизнесийн эзэн болон дансыг
иргэний баталгаажуулалттай (ДАН) тулгаж шалгана.

| Бизнесийн төрөл | Эзэн | Орлого хүлээн авах данс |
| --- | --- | --- |
| Хувь хүн | ДАН-аар баталгаажсан тухайн хүн | Тэр хүний өөрийн нэр дээрх |
| Байгууллага | Бүртгэлд нэрлэгдсэн захирал ДАН-аар батална | Байгууллагын нэр дээрх |

## Таны тохиолдол

| Нөхцөл | Хийх зүйл |
| --- | --- |
| Өөрийн бизнес | Өөрийн ДАН-аар бүртгүүлж, өөрийн нэр дээрх дансаа холбоно. |
| Хэрэглэгчийнхээ сайтыг хөгжүүлж байна | Хэрэглэгч өөрөө бүртгүүлээд таныг **Баг** хэсгээс гишүүнээр урина. |
| Ажилтан, гэр бүлийн хүн тусалж байна | Мөн адил: эзэн бүртгүүлж, туслах хүнээ гишүүнээр урина. |
| Нэг эзэмшигч, олон дэлгүүр | Шинэ бизнес нээхгүй. Дэлгүүр бүрт **project** нэмнэ. |
| Өөр регистртэй компанитай | Тэр компанид тусдаа бизнес бүртгэнэ. |
| Бусдын өмнөөс аль хэдийн бүртгэсэн | Бүртгэлд нэрлэгдсэн бодит эзэн Wire-ийн холбоосоор ДАН-аар батална. |

<Callout type="warn">
  **Нэг хуулийн этгээд = нэг бизнес.** Ижил регистрээр хоёр дахь бизнес бүртгэх
  хүсэлтийг дашбоард татгалзана. Дараагийн дэлгүүрээ байгаа бизнес дотроо
  project болгоно.
</Callout>

## Хөгжүүлэгч, агентлагт

1. Хэрэглэгч `app.wire.mn`-д **өөрийн ДАН-аар** бүртгүүлж, бизнесээ бүртгэнэ.
2. Хэрэглэгч таныг дашбоардын **Баг** хэсгээс гишүүнээр урина.
3. Та тэр бизнест project, холболт, API түлхүүр, webhook-ийг тохируулна.
4. Орлого **хэрэглэгчийн** нэр дээрх дансанд шууд орно.

Гишүүн эзэнтэй адил удирдана, харин устгах үйлдэл зөвхөн эзэнд. Өөрийн ДАН-аар
хэрэглэгчийн бизнесийг бүү бүртгэ: тэгвэл та тэр бизнесийн эзэн болж, дансны шалгалтад
тэнцэхгүй.

## Олон дэлгүүр, олон данс

Нэг бизнес дотор дэлгүүр бүрт тусдаа project үүсгэнэ (10 хүртэл). Project бүр өөрийн API
түлхүүр, webhook-той. Орлогоо өөрийн нэр дээрх өөр дансанд авах бол төлбөр бүрт
`settlement_account` заана. Дэлгэрэнгүйг [Олон данс](/docs/guides/settlement-accounts)
хуудсаас үзнэ үү.

## Зөвшөөрөгдөхгүй

- Гэр бүл, найз, ажилтны нэр дээрх дансаар орлого авах.
- Бусдын өмнөөс орлого цуглуулж, дараа нь шилжүүлэх.
- Өөр хүний ДАН-аар бизнес бүртгүүлэх.
- Хаагдсан бизнесийн оронд шинэ бизнес нээж төлбөрөө үргэлжлүүлэх.

## Шалгалт зөрвөл

Данс бизнесийн нэр дээр биш бол шинэ төлбөр `403 account_holder_mismatch` алдаагаар
зогсоно. Хийгдсэн гүйлгээнд нөлөөлөхгүй.

Энэ алдааг **дахин оролдох шаардлагагүй**. Дашбоардын **Данс** хэсэгт эзний нэр дээрх
дансаа нэмэхэд төлбөр автоматаар сэргэнэ. Бүртгэлийн эзэн таарахгүй бол бодит эзэн
ДАН-аар баталгаажуулна.
