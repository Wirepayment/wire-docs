## Мөнгө

Бүх дүн нь **бүхэл төгрөг (MNT), integer** — бутархай хэсэг, **мөнгө** гэсэн
нэгж байхгүй.

- `15000` гэдэг нь **15,000 ₮**. `50000` гэдэг нь **50,000 ₮**.
- Валют нь `MNT`.
- Бутархай эсвэл float хэзээ ч бүү илгээ; бүхэл тоо дамжуул.
- Нэг PaymentIntent 1-ээс 1,000,000,000 ₮ хүртэл (оператор өөрийн доод
  хязгаартай байж болно).

```json
{ "amount": 15000, "currency": "MNT" }
```

Дүнг тэр чигээр нь мянгатын тусгаарлагчтай харуул (`15,000 ₮`) — 100-д
**бүү** хуваа.

## Цаг

Бүх цагийн тэмдэг (timestamp) нь **UTC дахь Unix секунд** (жишээ нь `created`,
`expires_at`).

- Timestamp-г UTC-ээр хадгалж харьцуул.
- Монголд харуулахдаа **Asia/Ulaanbaatar** руу хөрвүүлж, `YYYY-MM-DD HH:MM:SS`
  форматаар бич.

```text
created = 1717000000   →  2024-05-30 00:26:40 (Asia/Ulaanbaatar)
```
