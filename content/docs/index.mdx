Wire бол нэгдсэн төлбөрийн gateway. Нэг удаа холбож, Монголын төлбөрийн
операторуудыг нэг API болон hosted checkout-оор хүлээн авна.

- **[Quickstart](/docs/quickstart)** — эхний төлбөрөө 5 минутад хүлээн ав.
- **[Оператор идэвхжүүлэх](/docs/guides/going-live)** — хүсэлт → хяналт →
  цахим гэрээ → live төлбөр.
- **[API reference](/docs/api)** — бүх `/v1` endpoint.
